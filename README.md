# Digital Signal Processing Filters

This repository contains practical implementations of fundamental Digital Signal Processing concepts using Python, NumPy, SciPy, and Matplotlib.

The work was completed using Google Colab and covers frequency-response analysis and digital filter design.

## Topics Covered

- Discrete-Time Fourier Transform (DTFT)
- Frequency-response analysis using `scipy.signal.freqz`
- Moving-average filters
- Inverse z-transform using `scipy.signal.residuez`
- DC component removal
- Notch filter design
- FIR low-pass filtering using the windowing method
- Effect of the number of filter taps on performance
